# Marth Lab

AP's Marth coaching app: matchup gameplans with Forest / Water / Mist styles, player scouting, a practice timer with streaks, set reviews with luckystats OPK tracking, and kill-percent reference.

**Use it:** open https://advancedplacement.github.io/marth-lab/ in Chrome on Android, then ⋮ → **Install app** (or **Add to Home screen**). It works offline after the first load.

Your drill logs and reviews are saved on the device in that browser only.
